Passo 1

Como criar um Apple ID ✨

O Apple ID será a identidade usada para entrar no Apple Developer, acessar o App Store Connect e administrar apps publicados. Para um app profissional, use uma conta que você consiga manter por muito tempo.

Roteiro guiado

Acesse a página oficial: abra appleid.apple.com.

Informe seus dados: nome, país/região, data de nascimento e e-mail que será usado nos serviços Apple.

Crie uma senha forte: misture letras, números e símbolos. Evite a mesma senha de redes sociais ou e-mail pessoal.

Adicione recuperação: telefone confiável e dados de recuperação ajudam muito se você perder acesso à conta.

Revise e aceite os termos: confira se os dados estão corretos antes de finalizar.

✅ Boa prática

Use uma conta dedicada ao projeto ou à empresa. Isso evita misturar arquivos pessoais com permissões de publicação.

⚠️ Atenção

Guarde acesso ao telefone e e-mail de recuperação. Eles podem ser exigidos em logins futuros.

Passo 2

Ativar autenticação de dois fatores 🔐

Antes de entrar no Apple Developer, proteja a conta. A autenticação de dois fatores é obrigatória para desenvolvimento iOS e publicação na App Store.

1️⃣

Acesse segurança

Abra os ajustes do Apple ID e revise telefone confiável, dispositivos confiáveis e senha.

2️⃣

Ative o 2FA

Siga o fluxo da Apple para confirmar um número de telefone confiável e habilitar autenticação de dois fatores.

3️⃣

Teste o acesso

Entre novamente no Apple Developer ou App Store Connect para confirmar que a validação funciona.

🔗 Link de apoio: appleid.apple.com

Passo 3

Apple Developer e App Store Connect 🧾

Depois do Apple ID, vem o Apple Developer Program. Em seguida, acesse o App Store Connect para aceitar termos, contratos e completar dados exigidos para publicação.

Passos principais

1. Acesse developer.apple.com.

2. Entre com o Apple ID criado e com 2FA ativo.

3. Inscreva-se no Apple Developer Program.

4. Pague a anuidade de US$ 99/ano e complete os dados pessoais ou da empresa.

Antes de pagar, confira

💳 Método de pagamento válido para a anuidade.

📄 Dados pessoais ou empresariais corretos.

📬 E-mail e telefone de contato que você acompanha.

Configurar App Store Connect

1. Acesse appstoreconnect.apple.com.

2. Aceite termos, contratos e políticas quando solicitado.

3. Complete contato, banco e impostos se for publicar o app.

Passo 4

Preparar o projeto Expo ⚙️

Antes do build, confirme que o app roda localmente e que o arquivo de configuração tem nome, slug, bundle identifier iOS e build number.

Checklist

✅ O app abre com expo start.

✅ expo.name está definido.

✅ expo.slug está definido.

✅ expo.ios.bundleIdentifier usa formato como com.seunome.app.

✅ expo.ios.buildNumber está planejado para uploads futuros.

app.json exemplo 
{
  "expo": {
    "name": "Meu App",
    "slug": "meu-app",
    "ios": {
      "bundleIdentifier": "com.seunome.meuapp",
      "buildNumber": "1"
    },
    "version": "1.0.0"
  }
}

Passo 5

Instalar EAS CLI e fazer login no Expo 👤

O EAS CLI é a ferramenta que conversa com os servidores da Expo para configurar credenciais, gerar builds e enviar releases.

Instalar EAS CLI 
npm install -g eas-cli
Login Expo 
eas login

Passo 6

Configurar EAS Build no projeto 🧰

No diretório do projeto, rode a configuração inicial e escolha iOS quando o assistente perguntar a plataforma.

Configurar build 
eas build:configure

development

Útil para desenvolvimento com cliente nativo.

preview

Bom para teste interno fora da loja.

production

Perfil usado para publicar na App Store.

Passo 7

Configurar credenciais Apple no EAS 🔑

O EAS pode gerar e gerenciar credenciais automaticamente durante o build. Para a maioria dos projetos, esse é o caminho mais simples no primeiro deploy iOS.

Revisar credenciais 
eas credentials

O que aparece aqui?

🔐 Certificado de distribuição: usado para assinar o app iOS.

🧾 Provisioning profile: vincula app, bundle identifier e distribuição.

🗝️ App Store Connect API key: opcional, útil para automatizar envio.

Passo 8

Fazer o build iOS com EAS 🏗️

Agora o EAS compila seu app nos servidores da Expo. Para envio à Apple, o resultado esperado é um arquivo .ipa.

Build de produção iOS 
eas build --platform ios --profile production

⏳ Aguarde

A compilação roda na nuvem e pode levar alguns minutos.

🔗 Link final

O EAS retorna um link para baixar o build.

📦 Artefato

Use o `.ipa` para envio ao App Store Connect.

Passo 10

Enviar o build para a Apple 📝

Depois que o EAS gera o .ipa, envie o build ao App Store Connect. Você pode usar EAS Submit ou o app Transporter no macOS.

Opção 1: EAS Submit

1. Execute o comando abaixo no projeto.

2. Escolha o build iOS gerado pelo EAS.

3. Siga o fluxo para enviar o .ipa ao App Store Connect.

Enviar com EAS Submit 
eas submit --platform ios

Opção 2: Transporter

🍎 Use esta opção em um Mac.

📦 Baixe o .ipa gerado pelo EAS.

🚚 Abra o app Transporter e envie o arquivo para o App Store Connect.

🧭 Aguarde o processamento antes de usar o build em TestFlight ou revisão.

Passos 11 e 12

Configurar metadados, screenshots e TestFlight ✅

Com o build processado no App Store Connect, complete os dados da página do app e escolha se vai testar primeiro pelo TestFlight ou enviar direto para revisão.

🧪 TestFlight interno

Ideal para validar instalação, login e fluxo principal com a equipe.

👥 TestFlight externo

Bom para ampliar validação com usuários selecionados antes da App Store.

🚀 Submit for Review

Envie quando metadados, privacidade, classificação e build estiverem prontos.

📝 Descrição, texto promocional e keywords.

🖼️ Screenshots para iPhone e, quando necessário, iPad.

🔒 Suporte, política de privacidade e informações de privacidade.

🎂 Classificação etária e demais declarações exigidas.

Fechamento

Aguardar aprovação e publicar 🏁

A Apple fará a análise do app. Quando aprovado, você poderá publicar na App Store. Se houver rejeição, corrija os problemas e reenvie o build ou os metadados necessários.

⏳ Revisão Apple

Acompanhe o status no App Store Connect e responda pendências quando aparecerem.

✅ Aprovado

Publique manualmente ou use a opção de liberação automática configurada no envio.

🛠️ Rejeitado

Corrija o item apontado, gere nova versão quando necessário e envie novamente.
